# Modules and packages

The pages of this group describe the optional parts of a profile. Each module needs an explicit selection in the overlay, and the example overlay enables none of them.

## Pages

- [The memory modules](memory-modules.md) - Hermes, LLM Wiki, OpenViking and AgentCore, with their consents and the data that leaves the machine.
- [The workflow modules](workflow-modules.md) - the MCP adapter, Promptr and the skill components.
- [The model routes](model-routes.md) - the native route, the direct route, the gateway route and the offline capability registry.
- [The in-tree packages](in-tree-packages.md) - the packages under `packages/`, which of them are kit components, and how each one is published.
