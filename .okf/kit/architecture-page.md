# The architecture page

The architecture page shows the environment that a selected Pi profile uses after the installation. It is a runtime map, not a scan of a machine and not an installer pipeline. Open `docs/architecture.html` from disk in a browser; the page needs no server, no network and no other file.

## The five views

| View | Shows |
| --- | --- |
| Installed environment | The terminal, the selected profile, local state, runtime code and service boundaries. The default view. |
| Profile & files | The process and its configuration, profile state, project files and shared account state. |
| Models & services | The three alternative model routes, and the optional MCP, knowledge, tracker and usage calls. |
| Memory & data | Each memory module, its storage scope, its transfer conditions and its effect on the model context. |
| Module catalog | Every manifest component with its source, inputs, consent, dependencies and readiness gaps. |

The catalog shows availability, not a detected selection. The page uses portable placeholders such as `$HOME/tenant-pi`; they do not identify an installation.

## Facts that the page states

- A profile is a configuration directory, not an operating-system sandbox.
- The model receives the prompt context, including recalled memory. Local memory storage does not mean that recalled text stays local.
- An optional service receives data only through its enabled, configured client.

## Build and check

`scripts/architecture_build.py` reads `docs/architecture/model.json` and `config/manifest.json` and writes the page. Edit the model or the renderer, then regenerate; never edit the generated HTML alone.

```sh
python3 scripts/architecture_build.py
python3 scripts/architecture_build.py --check
```

The `--check` form writes nothing and fails when the generated bytes differ. The unit tests check determinism, manifest coverage, file references and public-content rules.

Warning: the local edition (`--local`) holds host values from `docs/architecture/local-values.json`. Never publish it.
