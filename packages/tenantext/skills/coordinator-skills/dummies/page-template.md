## Update contract for agents

1. Read this page before you say where the project stands.
2. At the end of the work of a session, add one entry directly below the entries heading, above each older entry. The script `page.py add` of the dummies skill does it.
3. An entry heading has this form: `### Jan 5, 2026, 3:07 PM UTC | Agent: Pi | Model: example/model | Summary`. The time is the time of the write in the zone of the `timezone` field: a label and a fixed UTC offset, with no daylight-saving change. The model is the identifier of the session data. An alias stays an alias. A model that is not known is `unknown`.
4. Earlier entries stay as they are. A correction is a new entry that names the entry that it corrects.
5. An entry has the labels Important, Open, Next and Goal, in short sentences that teach a junior developer. An older entry can have the labels Goal, Executed, Relevance, Effects and Next: it stays as it is.
6. One item of the four labels is in CAPITAL LETTERS: the Important text, the most important item for a human reader. Keep a source change, a push, a build and a deployment apart.
7. Name the checks, the failures, the open limits, the commit identifiers and the endpoints. Write no credential into this page.
8. Add a Done table with five steps for work of more than one step. Keep a routine entry short.
9. Read before a write. Add the entry with one targeted edit. Do not replace the page.
10. Read the entry back after the write. One session writes one entry.

An agent adds each entry. No scheduler does it.
