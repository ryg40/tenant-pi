# Agent instructions

## Agent skills

### Issue tracker

Issues live in the development repository on Gitea. It is the `origin` remote of a development checkout. A snapshot clone from GitHub has no issue tracker. See [the issue tracker document](docs/agents/issue-tracker.md).

### Triage labels

`ready-for-agent` means that an agent can take the issue. `needs-approval` means that the owner approves before a worker starts. See [the label table](docs/agents/issue-tracker.md#labels).
